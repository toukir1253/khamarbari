# খামারবাড়ি — ১০ বিঘা সমন্বিত খামার

১০ বিঘা (১৬০ মি × ৯০ মি = ১৪,৪০০ বর্গমিটার) সমন্বিত খামারের ৩ডি দৃশ্য,
২ডি ম্যাপ, খামার পরিচালনা ও বিনিয়োগ সারসংক্ষেপ।

লাইভ: https://toukir1253.github.io/khamarbari/

## ফাইল

- `index.html` — ৩ডি খামার (Three.js r128, CDN থেকে লোড হয়; না চললে ২ডি ম্যাপ দেখায়),
  খামার পরিচালনা প্যানেল, দৈনিক রুটিন, আয়-ব্যয়ের হিসাব।
- `invest.html` — বিনিয়োগ সারসংক্ষেপ: খাতভিত্তিক আয়-খরচ, লাভ, রিটার্ন,
  ৩ বছরের প্রক্ষেপণ, ঝুঁকি ও সমাধান।

## সতর্কতা

- `invest.html`-এর টাকার অঙ্ক **নমুনা (বানানো)**। আসল হিসাব বসিয়ে নিতে হবে —
  এগুলো দিয়ে বিনিয়োগের সিদ্ধান্ত নেওয়া যাবে না।
- সব ডেটা শুধু ব্রাউজারের `localStorage`-এ থাকে। ব্রাউজার ক্লিয়ার করলে
  বা ফোন বদলালে মুছে যাবে। তাই মাঝেমধ্যে **এক্সপোর্ট / ব্যাকআপ ডাউনলোড**
  করে ফাইলটা নিরাপদে রেখো, প্রয়োজনে ইমপোর্ট করে ফেরত আনতে পারবে।

## ফোনে ধীর হলে

সেটিংস (⚙) থেকে **লাইট মোড** চালু রাখো — তাতে মুরগি ১০,০০০ থেকে
২,৫০০, ছায়া বন্ধ ও রেজোলিউশন কমে যায়, ফোনে দ্রুত চলে।
